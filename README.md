# Global Superstore Data Analysis

## Project Overview
Analyzed 51,290+ Global Superstore records to identify sales trends, profit patterns, regional performance, discount impact, and customer behavior.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Data Cleaning
2. Data Preprocessing
3. Exploratory Data Analysis (EDA)
4. Business Analysis
5. Data Visualization
6. KPI Dashboard

## Key Insights
- Analyzed sales and profit performance.
- Identified regional and category-wise trends.
- Evaluated the impact of discounts on profit.
- Studied customer purchasing behavior.
